kiwoom-backup

개인용 백업 도구입니다. 소유자 본인의 서버가 본인의 Google Drive 에 백업 파일을 올릴 때만 사용합니다.

Personal backup tool. Used only by the owner's own server to upload backup files to the owner's own Google Drive.

개인정보처리방침 / Privacy Policy

  • 이 앱은 이 앱이 직접 만든 파일에만 접근합니다(drive.file). / This app only accesses files it created (drive.file scope).
  • 어떤 개인정보도 수집·저장·공유하지 않습니다. / No personal data is collected, stored, or shared.
  • 소유자 본인 외에는 사용하지 않습니다. / Not offered to anyone other than the owner.
